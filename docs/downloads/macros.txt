# Optional printer macro installation

**Profiles work without these files on stock Sovol Zero 1.3.7 and 1.4.x.**
Install the macro pack once, even if you use multiple slicers. No MCU flash,
OTA or Klipper update is part of this installation.

## 1. Install one native config

Back up `printer.cfg` and any files you will replace. From `optional-macros/`,
copy **one** of these files into `~/printer_data/config/svzero/`:

| Installed firmware | File to copy |
|---|---|
| 1.3.7 | `svzero-1.3.7.cfg` |
| 1.4.x (checked against 1.4.7) | `svzero-1.4.x.cfg` |

On **1.4.x**, comment out the **entire** stock `[temperature_fan exhaust_fan]`
section, including its options: the pack replaces that fan and chamber sensor,
and both definitions cannot claim the same pins. Keep `[fan_generic fan3]`.
No stock-section removal is needed on 1.3.7.

In `printer.cfg`, after Sovol's `[include Macro.cfg]` and all stock fan/sensor
definitions, but **before `SAVE_CONFIG`**, add the matching line:

```ini
# For 1.3.7, use this line:
[include svzero/svzero-1.3.7.cfg]
```

```ini
# For 1.4.x, use this line instead:
[include svzero/svzero-1.4.x.cfg]
```

Do not include both firmware files or the modular source configs as well.
The chosen file contains all native macros and hardware overrides. It needs no
added Python modules. Comments naming source files describe the Git source
layout; those files are already consolidated and are not extra installation steps.

Recheck that the printer is idle immediately before restarting Klipper;
a restart aborts an active print. Before printing, review the brush geometry
in the consolidated file's `nozzle_brush.cfg` section. Use `BRUSH_STATUS` and
its documented `BRUSH_TEACH`/dry-run procedure to commission your own clearances.
The supplied pad bounds were measured on one machine, not guaranteed for yours.

The native pack adds chamber exhaust regulation, a rear-sensor chamber wait,
material-aware wiping, positioned purge, cancellation and a bed cooldown ramp.
Without Python, there is no nozzle-air qualification, bed boost or early handover.
An unreachable chamber minimum still requires changing the request or cancelling.
The cooldown ramp changes the bed target; `COOLDOWN_CONFIG ENABLE=0` disables it.
`COOLDOWN_ABORT` stops the ramp without turning heaters off; use `CANCEL_PRINT`
for shutdown and cancellation.

## 2. Optional adaptive preheat and Spoolman

Skip this section to retain native-only behavior. To enable both enhancements:

1. Copy `chamber_preheat.py`, `spool_guard.py` and `moonraker.py` from
   `optional-macros/` into `~/klipper/klippy/extras/`, backing up any existing files.
2. Copy `optional-macros/svzero-python.cfg` into `~/printer_data/config/svzero/`.
3. Add this include after your firmware include, before `SAVE_CONFIG`:

```ini
[include svzero/svzero-python.cfg]
```

With the printer idle, restart the **Klipper service** to load the Python modules.
`RESTART` and `FIRMWARE_RESTART` do not reload an already-imported module.
Do not enable the include before installing all three modules; configured
Python sections with missing modules prevent Klipper from starting.

Adaptive preheat qualifies the stirred nozzle as a chamber-air observer. Optional
boost/early handover is bounded; generated profiles do not enable bed boost by
default. A failed qualification or timeout remains an error. Spool guard checks
the active Spoolman spool before heating: absent integration is skipped with a
notice, while insufficient material or a configured integration's failure refuses
the print. See the consolidated config's comments for its explicit retry override.
To enable just one helper, use the individual feature configuration from Git;
the [advanced installation guide](https://github.com/rpcyan586/svzero-profiles/blob/main/INSTALL.md)
also covers separately configured fan/camera features.

## Updates and rollback

Replace the same consolidated file when updating; keep your personal tuning in
a separate config included last, before `SAVE_CONFIG`. Do not load source and
consolidated versions together. For a former modular installation, replace its
entry include with the consolidated one and remove duplicate source includes.

To remove Python, remove its include first and restart the Klipper service while
idle; the native fallback then takes over. To remove the native pack, remove its
include and restore any edited stock section (especially 1.4.x's exhaust fan),
or restore the backed-up configuration. Restart only when idle.

Keep the slicer's fallback skirt unless another priming sequence is in place.
Full source, builders, tests and optional feature configurations remain in the
[Git repository](https://github.com/rpcyan586/svzero-profiles).
